BookTalk 포트폴리오 스샷 준비하면서 발견한 버그들 수정하고 코드 정리한 내용

---

### 버그 1. 댓글 삭제 API URL 불일치

`CommentRestController`에서 매핑이 `/comment/delete/{no}`인데

프론트에서는 `/comment/delete/${no}/${isbn}`으로 호출하고 있었다

백엔드에서 `isbn`을 `@PathVariable`로 받으려는데 URL에 없으니 당연히 에러

```java
// 수정 전
@DeleteMapping("/comment/delete/{no}")

// 수정 후
@DeleteMapping("/comment/delete/{no}/{isbn}")
```

---

### 버그 2. 댓글 작성자 id가 null

소셜 로그인으로 인증 방식을 바꾸면서 `BookDetail.tsx`가 예전 코드 그대로였다

```tsx
// 수정 전 - sessionStorage에 id가 저장되는 시점이 없음
id: sessionStorage.getItem('id'),
name: sessionStorage.getItem('name'),
```

`/api/member/me` 응답에 `id`가 없었던 것도 문제였다

#### 해결

`/api/member/me` 응답 DTO인 `MemberResponse`에 `id` 추가

처음에는 `MemberController` 안에 inner record로 선언했는데, `MemberService`에서도 참조하다 보니 `dto` 패키지로 분리했다

```java
// com.sist.web.dto.MemberResponse
public record MemberResponse(Long id, String name, String email, String picture) {}
```

`BookDetail`에서 `useAuth()`로 교체

```tsx
const { member } = useAuth();

// ...
id: member?.id,
name: member?.name,
```

### 버그 3. comments 테이블 id 타입 불일치

`Comment` 엔티티의 `id` 필드가 `String`인데 `Member.id`는 `Long`이었다

외래키 역할도 못 하고 타입도 어색해서 통일했다

```java
// 수정 전
private String id;

// 수정 후
private Long id;
```

DB도 같이 변경

```sql
ALTER TABLE comments MODIFY COLUMN id BIGINT;
```

### 코드 정리

**Header.tsx 정리**

OAuth2로 인증 방식을 바꾸면서 일반 로그인 관련 코드가 dead code로 남아있었다

`useMutation`, `useState`, `useEffect` sessionStorage 체크 전부 제거

**console.log 제거**

`BoardUpdate`, `BoardDetail`, `BookDetail`, `YoutubeFind` 곳곳에 디버그용 `console.log`가 남아있었다

`console.error`는 에러 핸들링 용도라 유지

**기타**

- `BookList` 제목/저자/가격의 `<a href="#">` → 제목만 상세 페이지 `Link`로 교체
- 홈 새로운 책 Top6 `<a href="/w3images/lights.jpg">` → `Link`로 교체
- 홈 오늘의 책 링크 추가
- 뉴스 검색 초기값 `여행` → `개발`
- 게시판 이전/다음 버튼 액션 연결 + 1페이지 이전/마지막 페이지 다음 버튼 숨김 처리
- Express `tsconfig.board.json` 분리 (`moduleResolution: bundler`가 ts-node와 호환 안 되는 문제)

### 느낀 점

인증 방식 바꿀 때 연관된 코드를 전부 같이 안 바꿔서 버그가 생겼다

기능 단위로 바꿀 때는 그 기능을 사용하는 모든 곳을 같이 확인하는 습관이 필요할 것 같다
