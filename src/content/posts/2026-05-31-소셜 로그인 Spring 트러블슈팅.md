소셜 로그인을 붙이면서 백엔드에서 꽤 고생했다

문제가 하나씩 나오는데 원인을 찾기가 쉽지 않았다

---

### 문제 1. 로그인 후 쿠키가 안 심어짐

로그인은 되는 것 같은데 브라우저 Application 탭에 `access_token` 쿠키가 없었다

`SuccessHandler`에서 분명히 `response.addHeader`로 쿠키를 추가했는데

#### 원인

Spring Security OAuth2 필터가 처리 중인 `response`라

`addHeader`가 무시됐던 것

#### 해결

`response.addHeader` 대신 `ResponseCookie`를 사용하면 `Set-Cookie` 헤더가 정상 동작한다

```java
ResponseCookie cookie = ResponseCookie.from("access_token", token)
        .httpOnly(true)
        .secure(false)
        .sameSite("Lax")
        .path("/")
        .maxAge(Duration.ofMinutes(15))
        .build();

response.addHeader(HttpHeaders.SET_COOKIE, cookie.toString());
```

`SuccessHandler`에서 직접 쿠키를 설정하고 바로 리다이렉트하면 된다

URL에 토큰을 노출하지 않아도 되고 중간 API 호출도 필요 없어서 흐름이 훨씬 단순해졌다

---

### 문제 2. CustomException 핸들러가 없어서 401

`CustomException`이 발생하면 무조건 401이 떴다

#### 원인

`@RestControllerAdvice`에 `CustomException` 처리 핸들러가 없었던 것

그래서 Spring Security의 `authenticationEntryPoint`가 대신 잡아서 401을 반환했다

#### 해결

```java
@ExceptionHandler(CustomException.class)
public ResponseEntity<String> handleCustomException(CustomException e) {
    log.error("Custom error: {}", e.getErrorCode().getMessage());
    return ResponseEntity.status(e.getErrorCode().getStatus()).body(e.getErrorCode().getMessage());
}
```

핸들러를 추가해줬다

`HttpStatus.UNAUTHORIZED`로 하드코딩하면 `MEMBER_NOT_FOUND` 같은 경우도 401이 반환된다

`ErrorCode`에 `HttpStatus`를 포함시켜 각 에러코드별로 적절한 상태를 반환하도록 했다

### 문제 3. JWT 필터가 아예 실행이 안 됨

쿠키도 잘 담겨서 가는데 `/api/member/me`에서 계속 401이 떴다

백엔드 콘솔에는 아무 에러도 없었다

그래서 한참 헤맸는데

#### 원인

JWT 필터 WHITELIST에 `"/"`가 있었는데

`startsWith`로 비교하다 보니

```java
"/api/member/me".startsWith("/")  // true
```

모든 경로가 필터를 건너뛰고 있었던 것

에러가 없는 게 당연했다

#### 해결

```java
return WHITELIST.stream().anyMatch(white ->
    white.equals("/") ? path.equals("/") : path.startsWith(white)
);
```

`"/"`는 exact match로 처리했다

---

### 마무리

쿠키 문제가 제일 오래 걸렸다

`Set-Cookie` 헤더가 응답에 아예 없는 걸 확인하고 나서야 방향을 잡을 수 있었다

`response.addHeader`가 무시된다는 걸 몰라서 URL 파라미터 우회 방식을 썼는데

`ResponseCookie`로 바꾸니 `SuccessHandler`에서도 쿠키가 정상 동작했다

네트워크 탭으로 하나씩 확인하는 게 중요한 것 같다
