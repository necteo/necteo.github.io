# necteo.github.io

공부한 내용과 개발하며 마주친 문제를 기록하는 개인 블로그입니다.

**https://necteo.github.io**

## 다루는 내용

- Java, Spring Boot 기반 백엔드 개발
- Oracle, MySQL, MyBatis, JPA 등 데이터 접근과 테이블 설계
- Docker, Jenkins, AWS EC2를 활용한 배포와 CI/CD
- JSP, Vue.js, React 등 프론트엔드 학습 기록

## 개발

```bash
pnpm install
pnpm dev      # 개발 서버 (localhost:4321)
pnpm build    # 프로덕션 빌드
```

- 글: `src/content/posts/*.md`
- 사이트 설정: `src/config.ts`
- 프로젝트·타임라인 데이터: `src/data/`

## 기술 스택

[Astro](https://astro.build) · TypeScript · Tailwind CSS · Svelte

블로그 테마는 [Mizuki](https://github.com/matsuzaka-yuki/Mizuki)(Apache-2.0)를 사용했습니다.
